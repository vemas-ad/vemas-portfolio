## Cara paling mudah: GitHub → Vercel
1. Buat repository baru di GitHub, misalnya `vemas-portfolio`.
2. Upload **seluruh isi folder ini** ke root repository.
3. Login ke Vercel menggunakan GitHub.
4. `Add New` → `Project` → import repository `vemas-portfolio`.
5. Framework Preset: **Other**.
6. Root Directory: `./`.
7. Build Command: kosongkan / tidak perlu.
8. Output Directory: kosongkan / tidak perlu.
9. Klik **Deploy**.
10. Setelah deployment selesai, Vercel memberi domain gratis, misalnya `https://vemas-portfolio.vercel.app`.
11. Buka link dari HP/incognito dan cek login, semua project, gambar, video, serta dokumen.

## Update di masa depan
Edit file di GitHub atau upload versi baru lalu commit. Karena repository sudah terhubung ke Vercel, Vercel akan redeploy otomatis.
